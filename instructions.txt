CVM++ Compiler and Virtual Machine
==================================

## 1. Prerequisites
You will need a C++17 compatible compiler (such as g++ or clang++) to build the project.
No external dependencies or libraries are required.

## 2. How to Build
Open your terminal, navigate to the project root directory, and run the following command to compile the single-binary executable:

    g++ -std=c++17 -O2 main.cpp -o cvmpp

## 3. How to Run
The compiler and VM are bundled into a single executable called `cvmpp`.

- To run the interactive REPL:
    ./cvmpp

- To run a script file directly:
    ./cvmpp filename.cvm

- To compile a script, view the generated bytecode, and then execute it:
    ./cvmpp --debug filename.cvm
